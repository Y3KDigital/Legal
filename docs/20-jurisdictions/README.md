# Jurisdictions

This folder is organized as a set of **jurisdiction packs**.

Each pack contains:

- `overview.md` — high-level posture and scope
- `regulators.md` — regulators + definitions
- `classifications.md` — token classifications (draft)
- `flows.md` — what’s allowed / constrained for target product flows
- `sources.md` — primary sources only

Start with `jurisdiction-matrix.template.csv`.

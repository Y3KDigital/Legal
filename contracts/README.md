# Smart Contracts

Organize contracts by chain and product.

- `ethereum/` — Solidity contracts
- `solana/`, `cosmos/`, etc. — chain-native programs/modules
- `interfaces/` — cross-chain interface specs
- `audits/` — audit reports and checklists

## Note

This repo includes templates and placeholders. Select one toolchain (Foundry or Hardhat) once the team decides.
